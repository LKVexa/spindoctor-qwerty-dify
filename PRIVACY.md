# Privacy

SpinDoctor Qwerty for Dify runs entirely inside the Dify plugin runtime. It makes no network calls of its own and collects no data. Uploaded files are read from the Dify file server only when you pass them to a tool, are written to a temporary folder for that call, and are deleted afterwards. Simulator state and reports are written to a local workspace folder on the plugin host (default: the system temp folder).
